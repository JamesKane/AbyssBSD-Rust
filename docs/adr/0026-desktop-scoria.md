# ADR-0026: The desktop is Scoria, a Rust tiling Wayland desktop built in this workspace

- Status: Accepted
- Date: 2026-11-23
- Supersedes: [ADR-0018](0018-desktop-architecture.md)

## Context

ADR-0018 made M-D the AbyssBSD monorepo's desktop (`undertow` over wlroots, the Aqua shell and
applications, application jails, the installer), run here unmodified from packages, with this
repository building only the kernel beneath it.

Scoria is a different desktop, designed for FreeBSD from the start: a tiling Wayland compositor
with a Vulkan 1.3 renderer, a small session supervisor, one typed IPC over `SOCK_SEQPACKET`, one
libucl configuration with atomic reload, interaction rules taken from the 1978–1997 human-interface
research, and a design centered on gaming, ricing, and streaming. Its design was written for
Odin (`~/Projects/desktop/scoria/docs/design.md`). The owner chose it over the monorepo desktop
on 2026-11-23, to be written in Rust in this workspace.

## Decision

1. **M-D is Scoria.** [DESKTOP.md](../DESKTOP.md) is its design, carried from the Odin design into
   Rust. The monorepo desktop is no longer AbyssBSD's desktop. It may still run here as any
   FreeBSD userland does, but nothing is scheduled for it.
2. **Scoria is Rust in this workspace**, under a new top-level `desk/`, with pure, host-tested code
   in `lib/` (`lib/cbor`, `lib/tiling`, `lib/contrast`). Pinned stable Rust (ADR-0003). `desk/`
   uses `std` and targets FreeBSD 15.1; amd64 first, aarch64 once DESKTOP.md §14 question 2 is
   answered.
3. **ADR-0002 is amended for `desk/` only.** C libraries from FreeBSD packages or `base.txz` may be
   linked dynamically, each through one FFI crate in `desk/ffi/` with in-house bindings checked in
   (generated by `tools/waylandgen` and `tools/vkgen`, or written by hand) and layout tests. No
   `bindgen`, no `-sys` crates, and still no Rust crates from any registry. Every library is listed
   in `desk/ffi/inventory.ucl`, which `cargo xtask check` enforces. C parsers that see untrusted
   input run only in the Capsicum worker. GPL libraries are not linked, and their headers are not
   read (ADR-0007). The kernel, the loader, and `lib/` are unchanged.
4. **Scoria is ordinary FreeBSD 15.1 userland.** It uses only the FreeBSD ABI and the Direct
   Rendering Manager interface of [ADR-0025](0025-graphics-abi-and-native-drivers.md), probes every
   kernel feature at run time, and ships as one FreeBSD package that installs on AbyssBSD and on
   stock FreeBSD 15.1.
5. **RDNA2 stays the first native amd64 GPU**, as ADR-0018 decided (GRAPHICS.md §13 question 1):
   the X870E, the Z690-A, and the B650E all have it.
6. **Measured as a component** under [ADR-0014](0014-performance-parity-per-component.md): each
   `desk.*` benchmark against the same package on FreeBSD 15.1 on the same machine, in bhyve for
   the headless benchmarks and with `drm-kmod` on metal. Scoria's tests run on both systems, and
   differences are listed as kyua's are.

## Consequences

- No desktop source came from outside before; now this workspace carries a compositor, a
  supervisor, satellites, and FFI crates. The amendment's inventory is the limit on what that
  brings in.
- **Kernel work the monorepo desktop needed and Scoria does not** leaves M-D:
  - nullfs and application jails (`abyss-jaild`): nullfs stays on the list for
    [WINDOWS-GAMES.md](../WINDOWS-GAMES.md) stage W5 and VFS.md's follow-ups, no longer M-D.1;
  - the monorepo harness as a conformance suite (`run.sh --live`, `--full`): replaced by Scoria's
    own suites, run on both systems;
  - the monorepo's desktop asks (arm64 packages, a FreeBSD form of its GPU lanes, a harness mode
    without ssh, the Vulkan renderer for `undertow`): withdrawn. The installer-side asks (a 15.1
    package build, a UFS install layout, the medium recipe's inputs) stay until INSTALLER.md is
    revised;
  - `snd_dummy` for the harness's sound lanes: AUDIO.md A1 keeps it, with its own exit.
- **Kernel work Scoria adds** (DESKTOP.md §11.3): syncobj timelines with `SYNCOBJ_EVENTFD`, atomic
  asynchronous flips, variable refresh and damage clips, game-controller drivers, and `cuse`
  (or AUDIO.md's taps) for stream audio. The MAC framework with `mac_priority`, `sound(4)`, and
  ACPI sleep, buttons, battery, and AC adapter stay.
- **The installer and login** came with the monorepo desktop. [INSTALLER.md](../INSTALLER.md)
  keeps its plan until revised; how it and a login screen fit Scoria is DESKTOP.md §14 question 7.
  GELI and ZFS (M-Z) stay with the installer.
- The window model is tiling, with scrollable tiling by default and floating and monocle as
  first-class modes. There is no Aqua look, global menu bar, or Finder.
- No OBS plugin comes from this project, since OBS's plugin interface is GPL. Scoria offers the
  standard capture protocol; how OBS uses it and whether Scoria controls OBS is open
  (DESKTOP.md §14 question 9).
- ADR-0018's other decisions stand where they did not depend on the monorepo desktop: RDNA2
  (decision 5) and FreeBSD 15.1 as the desktop's userland.
