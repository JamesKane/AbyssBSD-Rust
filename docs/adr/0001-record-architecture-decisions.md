# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-17

## Context

This is a long-lived, from-scratch OS project. Its design choices (ABI targets, toolchain policy,
kernel structure) will be questioned again later, by future contributors and by ourselves.

## Decision

We record significant decisions as numbered ADRs in `docs/adr/`, using the template in the README.

## Consequences

Decisions are discoverable and their reasoning survives. Reversing one means writing a new ADR that
supersedes it.
